# Contributing

Thanks for helping build TensorFoundry! We welcome issues, ideas, and pull requests.

## Development workflow
- Create a feature branch from `exp` (or `dev` if in use); avoid committing directly to `prod`.
- Keep PRs small and focused. Include tests where possible.
- Run lint and tests locally before opening a PR.
- Add documentation or examples when introducing new behaviors.

## Commit and PR guidelines
- Write clear commit messages that explain the change and the motivation.
- Use drafts for WIP. Mark PRs ready once checks pass.
- Link issues and include screenshots or logs when helpful.

## Code style
- Python 3.10+; prefer type annotations and small, composable functions.
- Favor explicitness over cleverness. Add brief comments when intent is non-obvious.

## Communication
- Be respectful and constructive. See `CODE_OF_CONDUCT.md`.
- If you are unsure about direction, open an issue before writing code.
