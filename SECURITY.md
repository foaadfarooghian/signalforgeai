# Security Policy

We take security seriously and appreciate responsible disclosures.

- **Reporting**: Email security issues to the maintainers privately. Avoid filing public issues for vulnerabilities.
- **Scope**: Core library (`src/tensorfoundry`), orchestration components, and official examples.
- **Response**: We aim to acknowledge reports within 2 business days with next steps and timelines.
- **Disclosure**: Please allow us time to investigate and patch before public disclosure.
